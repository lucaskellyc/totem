Repo Demo

Totem is an experimental art project started as a college senior project. The experience features scrollable columns of dynamically lit multimedia displays — video, water, blinking bulbs, spinning parts and spatially-anchored sound, all composited through a bloom-and-fisheye post chain.

Under the hood it's a small, open-source three.js library: describe a stack of blocks with plain specs and Totem loads, lights and animates them.

What's inside

VideoTextures that play video, gated to what's on screen
WaterCustomizable shader-driven flowing water surfaces
LightsBlinking emmissive light sources, like neon signs
SpinContinuous rotation on any axis
SoundSpatially-anchored positional audio
FiltersBloom, fisheye and edge-blur post FX

Use it in your project

npm i three
npm i github:lucaskellyc/totem
import { Totem } from "totem";

const totem = new Totem();
scene.add(totem);

await totem.loadBlocks([
  { url: "/block.glb", texture: "/block.jpg" },
]);

totem.update(); // in your render loop
