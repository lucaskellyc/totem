# Totem v0.2.0-alpha

> ⚠️ **Alpha pre-release.** APIs may change without notice.

An experimental block-based 3D scene builder for [three.js](https://threejs.org/). This release splits the library into a base class plus opt-in effect modules, makes `Totem` a `THREE.Group` subclass, and adds water/video/sound/filter effects.

**[Live demo](https://lucaskellyc.github.io/totem/)**

## Added

- **`spec.object`** on blocks and components — accepts a `THREE.Object3D` or a factory returning one, as an alternative to `spec.url` (GLB). Inline any three.js primitive or custom mesh with no per-type registration.
- **`lib/extras/water.js` — `WaterEffect`.** Opt in via `type: "water"`; swaps in a shader-modified `MeshStandardMaterial` with animated flow noise.
- **`lib/extras/video.js` — `VideoEffect`.** Opt in via `spec.video` (URL string or `{ url, loop, muted, playbackRate, autoplay, … }`). Playback pauses when the block leaves focus range or the tab is hidden.
- **`lib/extras/sound.js` — `SoundEffect`.** Spatially anchored `THREE.PositionalAudio` via `spec.sound`, with optional smoothstep volume fade based on world-Y distance to `focusY`.
- **`lib/extras/filters.js` — `Filters`.** `EffectComposer` wrapper with configurable `bloom`, `fisheye`, and `edgeBlur` passes plus a final `OutputPass`.
- **`lib/totem/gestures.js`** — wheel + pointer-drag gestures with autoscroll/resume, now a first-class base module (moved from extras).
- **`lib/totem/lights.js`** — attaches `PointLight` records to a block group with per-light `castShadow`/`distance`/`power` and focus-based intensity fade.

## Changed

- Repository layout: `lib/` split into `lib/totem/` (base `Totem` class, loaders, materials, shadows, gestures, lights) and `lib/extras/` (opt-in effect classes).
- `Totem` is now a `THREE.Group` subclass — add it directly to your scene.
- `Totem` exposes `_decorateBlock(...)` and `_updateExtras(t)` hooks so effects can be composed at the demo level without subclassing.
- Shadow map defaults tuned for performance (mapSize `512`, `PCFShadowMap`, `castShadow` gated by focus-based intensity).

## Removed

- `lib/totem/primitives.js` — bulb meshes and plane primitive support.
- Light behaviors (`pulse` / `blink` / `flicker`).
- `spec.planes` field — use `spec.components` with `object` for inline planes.
- `lib/extras/effects.js` composite subclass — wire individual effects at the demo level.
- `lib/totem/mount.js` helper — inline the `WebGLRenderer` / `Scene` / animate loop in your demo.

## Install

```bash
npm i three
npm i github:lucaskellyc/totem#v0.2.0-alpha
```
